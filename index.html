Introduction

The Procrastination Preventer Our project, the procrastination preventor relates closely with the goal of Quality an education because it helps any student that struggles with any distractions specifically on their phone by putting it in a locked box where it cannot be accessed for a period of time making them be more focused on their work rather than scrolling.

What Does The Project Need To Do

  • Automated Motorized Locking & Unlocking: A 5V stepper motor closes the door shut when a countdown starts and opens when the timer ends.
  • Keypad-Driven Dual Timers: The user inputs a durations for both a Study Timer and a Break Timer using the keypad.
  • Visual Telemetry & Status LEDs: A 1602A LCD screen displays live time, while LEDs (Red, Green, Blue) visually signal system states (e.g., Red = Locked/Study, Green = Unlocked/Break, Blue = Menu Setup).
  • Charging & Headphone Cable Passthrough: A cut-out port allows charging or wired audio access while keeping the phone inside.

How We Know If It Works Well

How we would measure its success is firstly if the box is able to close and open on its own, opening and closing when the timer is set and ends.secondly the box has to lock in place to prevent anyone from getting the phone before its timer ends serving its main purpose.thrid has an indicator for the user to confirm that it is locked and cannot be opened. Lastly this is more of a gimmick but has a hole for its charging port or wired headphones to be accessed.

What Might Make It Harder To Finish

The more difficult part of the project would have to be coding the functions of the system such as, the motor that closes/opens the door, the keypad display that takes inputs for time,the Light indicator that turns green and red based on if it's unlocked or not.

  • Stepper Motor Torque & Driver Supply: The stepper motor requires step sequencing and stable power draw to open and close smoothly this is why we only get to use one for it to be compatible with the arduino.

Circuit Diagram (THIS SECTION IS TO BE EDITED)

The potentiometer sets the timer duration, which is displayed live on the 16x2 LCD screen. Pressing the start button triggers the SG90 servo motor to rotate 90 degrees and engage the physical box latch. The Arduino counts down the remaining time on the LCD screen, holding the servo locked until the timer reaches zero.

Environmental Impact Assessment (THIS SECTION IS TO BE EDITED)

  • Materials: Keypad: one part instead of many buttons, so less manufacturing and waste, 1 motor: roughly half the resource impact of 2, Fewer components means less e-waste (goals 7 & 12).1 motor uses less copper, magnet material, and housing, A keypad uses less plastic and wiring than separate buttons.
  • Energy Efficiency: 1 motor draws less total power per lock cycle, A keypad scans fewer lines than many buttons, and staying within the microcontroller’s limits allows a smaller, lower-power chip.
  • Reusability: A keypad is standard and easy to replace or reuse, Spare inputs let you reprogram the circuit later.
  • Packaging & Shipping: Fewer parts mean a smaller, lighter product and less packaging.

Arduino Code (THIS SECTION IS TO BE EDITED)

The following C++ program reads time selection from the potentiometer, displays the live countdown on the I2C LCD, and actuates the servo motor latch mechanism upon button press.


#include <Wire.h>
#include <LiquidCrystal_I2C.h>
#include <Servo.h>

// Hardware Pins
const int potPin = A0;
const int buttonPin = 2;
const int servoPin = 9;

// Objects
LiquidCrystal_I2C lcd(0x27, 16, 2);
Servo lockServo;

// Constants & State Parameters
const int LOCKED_POS = 90;   // Servo locked angle (degrees)
const int UNLOCKED_POS = 0;  // Servo unlocked angle (degrees)
bool isLocked = false;
int minutesToLock = 1;

void setup() {
  pinMode(buttonPin, INPUT_PULLUP);
  lockServo.attach(servoPin);
  lockServo.write(UNLOCKED_POS);

  lcd.init();
  lcd.backlight();
  lcd.setCursor(0, 0);
  lcd.print("Set Time (Mins):");
}

void loop() {
  if (!isLocked) {
    // Read potentiometer value (maps 0-1023 analog input to 1-60 minutes)
    int potVal = analogRead(potPin);
    minutesToLock = map(potVal, 0, 1023, 1, 60);

    lcd.setCursor(0, 1);
    lcd.print("Timer: ");
    if (minutesToLock < 10) lcd.print("0");
    lcd.print(minutesToLock);
    lcd.print(" mins   ");

    // Check start button press (Active LOW using internal pull-up)
    if (digitalRead(buttonPin) == LOW) {
      delay(50); // Debounce delay
      if (digitalRead(buttonPin) == LOW) {
        startLockdown(minutesToLock);
      }
    }
  }
  delay(100);
}

void startLockdown(int totalMinutes) {
  isLocked = true;
  lockServo.write(LOCKED_POS);

  long totalSeconds = (long)totalMinutes * 60;

  while (totalSeconds > 0) {
    long minsLeft = totalSeconds / 60;
    long secsLeft = totalSeconds % 60;

    lcd.setCursor(0, 0);
    lcd.print("   LOCKED OUT!  ");
    lcd.setCursor(0, 1);
    lcd.print("Time: ");
    if (minsLeft < 10) lcd.print("0");
    lcd.print(minsLeft);
    lcd.print(":");
    if (secsLeft < 10) lcd.print("0");
    lcd.print(secsLeft);
    lcd.print("   ");

    delay(1000);
    totalSeconds--;
  }

  // Timer finished - release lock mechanism
  lockServo.write(UNLOCKED_POS);
  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print(" Time's Up! ");
  lcd.setCursor(0, 1);
  lcd.print(" Box Unlocked ");
  delay(5000);

  isLocked = false;
  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print("Set Time (Mins):");
}
